# TokenBasedReplayForPartialOrders
If you reached this repository due to the reference in the Petri nets 2026 conference publication "Conformance Checking for Partially Ordered Event Logs Using Token-Based Replay"
please refer to the branch "ConferenceBranch" for the state of the code the paper is referring to. 

In this branch the code refers to the SoSyM Journal Extension of the above-named paper. It includes additional logic and offers a streamlit web interface for interactive use, accessible via https://po-track.ds.fernuni-hagen.de.
